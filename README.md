# Freelancer

Sitio web de servicios freelance desarrollado como parte de mi formación en desarrollo web.

## Descripción

Este proyecto consiste en una página web responsive para presentar servicios de diseño y desarrollo web.

Durante su desarrollo puse en práctica conceptos fundamentales de HTML y CSS, incluyendo estructura semántica, navegación, formularios, diseño responsive y organización de estilos.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Scroll Snap
- Normalize.css

## Características

- Diseño responsive
- Navegación principal
- Sección de servicios
- Formulario de contacto
- Adaptación para diferentes tamaños de pantalla
- Efecto Scroll Snap en distintas secciones
